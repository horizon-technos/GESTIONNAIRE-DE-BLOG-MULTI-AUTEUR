# API Gestionnaire de blog multi-auteur

## Presentation du projet

ce projet est l'aboutissement de la formation **"Developeur Backend debutant"**. Il sagit d'une **API REST Complete**

L'objectif principal est de synthetiser et de valider **l'integralite des modules** vus durant la formation, en partant de la modelisation des donnees jusqu'au deploiement, en passant par la securite, l'authentification et les tests.
